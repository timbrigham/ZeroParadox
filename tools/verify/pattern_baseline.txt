# answered "would it recognise anything". Measured by mutation -- replacing each advertised pattern
# with a string that cannot match, one at a time, then re-running that checker's own --selftest --
# 30 of 34 list-shaped patterns were SILENT. Deleting `artifact` from check_modal's list stops it
# catching the defect class it was built for, with --selftest green and --block exit 0. A survey then
# found ~39 compiled regexes carrying the rest of the vocabulary, none pinned at all.
#

# stops catching. For an EVIDENCE or suppression pattern it is ADDITION: one more alternative
# silently clears more hits. A superset test is right for a list of things to catch and wrong for a
# list of excuses. So a legitimate change to any pattern updates this file in the same commit -- a
# reviewable act, and this file is in `batch.CHECKERS`.
